# Agents

This repository uses shared action helpers for agent scripts located at scripts/lib/actions.sh (renamed from director_actions.sh).

How to use:
- Source scripts/lib/actions.sh from agent scripts to access shared action functions.
- Add new agent scripts under scripts/agents/ or scripts/lib as appropriate.

Note:
- The previous filename director_actions.sh was shortened to actions.sh to be more generic and reusable across multiple agents.
