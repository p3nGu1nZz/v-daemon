v-daemon is a lightweight POSIX-shell daemon and developer harness for a Director/Worker self-improvement loop, with scaffolding for future CMake/C++ sources under src.  
Key files: README.md, TODO.md, scripts/{setup.sh,check.sh,run.sh,build.sh}, scripts/lib/{daemon.sh,director.sh,director_actions.sh,[process.sh]}, external/Catch2, logs/, dev/audits/.  
Build/run: use scripts/setup.sh to install deps and fetch Catch2; create an out-of-source build (mkdir build && cd build && cmake -G Ninja ..) and build with ninja -j$(nproc).  
Tests: Catch2 is fetched into external/Catch2; add a top-level CMakeLists.txt to enable test targets, then run ctest or ninja test after configuring the build.  
Current behavior: daemon and director stubs write PID files and periodic heartbeats; director can run an autopilot summary (uses copilot CLI if available) and both use simple lock/pidfile semantics.
